# Pixel Office (VS Code)

이 작업 폴더에서 일하는 Codex와 Claude Code를 픽셀 사무실로 보여 준다. VS Code 창을 폴더와 함께 열면 편집기 옆 탭에 사무실이 자동으로 열린다.

- 명령 팔레트: "Pixel Office: 사무실 열기"
- 설정: `pixelOffice.autoOpen` (자동 열기 끄기)

에이전트의 상태를 받으려면 훅이 필요하다. 저장소에서 `npx pixel-office init`을 실행한다. 자세한 내용은 https://github.com/kimcheolhui9846/pixel-office 의 README에 있다.
